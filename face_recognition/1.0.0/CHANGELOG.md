# 更新日志

## 1.0.0 (2026-06-06)

### 新增功能

- **人脸检测**: 基于InsightFace buffalo_l模型的高精度人脸检测
- **人脸特征提取**: 提取512维人脸特征向量
- **人脸识别**: 1:N人脸识别，支持身份比对
- **人体检测**: 基于YOLOv8-n的人体检测
- **人体追踪**: 可选ByteTracker人体追踪
- **质量评估**: 人脸质量评分和过滤

### 技术特性

- 支持ONNXRuntime推理引擎
- 支持动态参数配置
- 支持C ABI接口
- 支持热更新
- 支持自检功能

### 配置参数

- `conf_thres`: 人体检测置信度阈值
- `iou_thres`: NMS IOU阈值
- `enable_tracker`: 是否启用ByteTracker人体追踪
- `face_conf_thres`: 人脸检测置信度阈值
- `face_quality_thres`: 人脸质量阈值
- `max_faces`: 单帧最大人脸数

### 输出格式

- 支持人脸识别结果JSON格式
- 支持类别编码（13001: 已识别人员, 13002: 未知人员, 13003: 人员）
- 支持边界框、关键点、置信度、相似度等信息
- 支持追踪ID

### 模型要求

- InsightFace buffalo_l模型
- YOLOv8-n模型
- 支持ONNX格式

### 硬件支持

- 支持x86_64架构
- 支持RK3588/RK3576平台
- 支持GPU加速（可选）

### 依赖项

- OpenCV 4.x
- ONNXRuntime 1.x
- jsoncpp
- CMake 3.16+

### 已知问题

- 首次运行需要初始化模型，可能需要较长时间
- 大规模人脸库可能影响识别速度
- 需要足够的内存和计算资源

### 下一步计划

- 支持更多模型格式
- 优化推理性能
- 增加更多配置参数
- 支持批量处理
- 增加更多测试用例
